## 三、核心速查

### 权限

| 数字 | 用途 |
|---|---|
| 644 | 普通文件 |
| 755 | 目录、可执行脚本 |
| 600 | 私密文件 |
| 777 | 所有人全权限（危险） |

**umask 022 → 文件 644、目录 755**（按位去掉，不是十进制减法）

**特殊权限**：SUID=4（属主位 s）、SGID=2（属组位 s）、SBIT=1（其他人位 t）
例：`/usr/bin/passwd` 是 `-rwsr-xr-x`，`/tmp` 是 `drwxrwxrwt`

### 磁盘

**四步：分 → 格 → 挂 → 写**

```bash
fdisk /dev/sdb
mkfs.ext4 /dev/sdb1
mount /dev/sdb1 /mnt/data
# 再写 /etc/fstab
```

**fstab 六字段**：设备 · 挂载点 · 类型 · 选项 · 备份 · 检查

```
UUID=xxx  /mnt/data  ext4  defaults  0  2
```

**LVM**：`pvcreate → vgcreate → lvcreate → mkfs`（物理卷 → 卷组 → 逻辑卷，从小到大）

**RAID**：0 无冗余 / 1 镜像 / 5 至少 3 块、容 1 块坏

### 服务与 SELinux

```bash
systemctl start sshd     # 现在启动
systemctl enable sshd    # 开机自启（不马上启动）
journalctl -u sshd -f
```

SELinux 三模式：**enforcing**（拦截）/ **permissive**（只记录不拦截）/ **disabled**（关闭）

### 重定向

| 符号 | 含义 |
|---|---|
| `>` | 覆盖 |
| `>>` | 追加 |
| `2>` | 只存**报错** |
| `&>` | 正常 + 报错全存 |

（0 标准输入、1 标准输出、2 标准错误）

## 四、当晚踩的 5 个坑

**1. 大小写 ≠ 同一个东西**

| 敲错 | 应该 | 现象 |
|---|---|---|
| `-q0-` | `-qO-` | `wget: invalid option -- '0'` |
| `ls -z` | `ls -Z` | `无效的选项 -- z` |
| `E0F` | `EOF` | heredoc 永远结束不了 |

**只要报“无效的选项”，先怀疑大小写。**

**2. 把文档里的斜杠当命令抄**

看到 `systemctl stop / restart / status`，我直接敲了 `systemctl stop/restart/status`。

**斜杠是“三选一”，不是命令的一部分。** 正确是 `systemctl stop sshd`。

**3. `Too few arguments` = 参数不够**

`systemctl stop` 少了服务名，报错是“参数太少”，不是“命令不存在”。

**4. 命令依赖当前目录**

`cd /tmp/perm` 报“没有那个文件或目录”，因为 `/tmp` 在重启后被清空了。**先建再用。**

**5. 路径存在与否要先确认**

`ls -Z /var/www/html` 报不存在——宿主机从来没装过 nginx（nginx 一直跑在容器里）。**别假设路径存在。**

## 五、一个意外发现

```bash
getenforce
# Permissive
```

**我的系统 SELinux 早就是 `Permissive` 了**（只记录，不拦截）。

这意味着：之前排查“网站访问 403”时，如果 SELinux 是 Permissive，那 403 就**不是** SELinux 造成的，别往那个方向乱改。

**教训：先看当前真实状态，再套用经验。**

## 六、易混 10 组（考前最后一遍）

1. `644` 文件 / `755` 目录和脚本 / `600` 私密
2. umask 022 → 文件 644、目录 755
3. `start` 现在启动 / `enable` 开机自启
4. fstab：设备 · 挂载点 · 类型 · 选项 · 备份 · 检查
5. LVM：pvcreate → vgcreate → lvcreate → mkfs
6. RAID 0 无冗余 / 1 镜像 / 5 容 1 块
7. `>` 覆盖 / `>>` 追加 / `2>` 错误 / `&>` 全部
8. `kill -9` 强制 / `-15` 默认优雅
9. SUID=4 属主位 / SGID=2 属组位 / SBIT=1 其他人位
10. 软链接 inode 不同（删源失效）/ 硬链接 inode 相同
